# Note Detection

ever had the problem of when you are playing an instrument, 
you get into the flow state, 
create something extrodinary beautiful and for the love of god cant replay it exactly and dont remember what you played ?

well that happened to me a lot, so im trying to make a software that listens to your instrument and then detects what note you are playing based on well physics and frequencies and then store them.

there are a lot of design ideas in mind to how to make this happen which i need to test out 
AND if everything worked correctly i want to see if i could also make it embedded C++ and use an esp32 and a mic to have a carry on notes transcriber.
